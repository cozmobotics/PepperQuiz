# PepperQuiz
Ein Python script, das auf dem Tablet des Pepper Roboters ein Multiple-Choice-Quiz mit anklickbaren buttons darstellt. Die Fragen und Antwort-Optionen werden (optional) von Pepper ausgesprochen und durch Bewegungen untermalt. 

* quizPepper.py ... Das Haupprogramm
* doJavascript.py ... Funktionen zur Darstellung auf dem tablet
* animationMartin.py ... Funktionen für Aussprache und Gesten 
* 2.json ... ein Beispiel für die Definition von Fragen
* listQuestions.py ... Hilfsprogramm, um Fragen aus einem json-file aufzulisten, erzeugt html. 
* PepperQuizDoku.pdf ... Die Doku
